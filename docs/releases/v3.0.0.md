# API Tester v3.0.0

The biggest update so far: a completely new interface, background monitoring with a tray icon and a browser
dashboard, collection inheritance, secret variables and a built-in updater. Your collections, environments,
history, monitors and settings carry over unchanged.

## Highlights

**New interface**
- Modern WPF window (the default) with Light/Dark themes that switch instantly, fitted to your screen.
- Syntax highlighting with line numbers, `{{variable}}` hover with the resolved value, a Params tab, test snippets.
- Request tabs with "+" / close buttons, one request per tab, drag to reorder, open a request in its own window.
- The previous window is still there: start with `-ClassicUi`.

**Collections and runs**
- Folder and collection settings (auth, headers, scripts) inherited by requests - like Postman.
- Import from Postman, Insomnia, HAR and OpenAPI; export to Postman v2.1.
- History keeps responses: view them and compare them offline.
- Collection runner with parallel requests, retries and an HTML report; headless `-OutputFormat Html` and `-Retries`.

**Monitors**
- Keep running in the background with a status tray icon - after closing the app, at Windows sign-in, or as a scheduled task while nobody is signed in.
- Live dashboard in the browser (`http://127.0.0.1:8765/`), p50/p95/p99 latency.
- Retries before alerting, quiet hours, down/recovered alerts, Teams / Slack / webhook alerts.

**Security and updates**
- Secret variables: masked on screen, encrypted on disk, never exported.
- Help -> About checks for updates (also once a day in the background); downloads are checksum-verified.

## Important fixes
- Windows PowerShell 5.1 now loads and saves environments and global variables.
- Requests with `Accept`, `User-Agent` and other restricted headers work; TLS 1.2 is enabled on older .NET.
- Headless runs use the full request engine (auth, bodies, scripts, tests, variables).
- Deeply nested collections are no longer truncated when saved.

## Upgrading
- **From the app:** Help -> About API Tester -> Check for updates -> Download & update, then restart.
- **Manually:** download `API-Tester.ps1` below and replace your copy. Keep the `Configuration`, `History` and `Logs` folders next to it.
- Requires Windows PowerShell 5.1 or PowerShell 7 on Windows.

The full list of changes is in [CHANGELOG.md](https://github.com/imumeshk/API-Tester/blob/main/CHANGELOG.md).
