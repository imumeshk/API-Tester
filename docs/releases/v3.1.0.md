# API Tester v3.1.0

A polish and performance release: an instant light/dark switch, your own keyboard shortcuts, tidier windows and a
noticeably faster start.

## Highlights

**Theme in one click**
- New ☾ / ☀ button in the header (or **Ctrl+Shift+D**). The theme changes straight away - no restart, the window stays
  open, and running requests, tabs and responses are not affected.

**Your own keyboard shortcuts**
- **Help -> Keyboard Shortcuts...** (**F1**): change any of 18 actions, with checks for duplicates and editing keys.
- New defaults: **Ctrl+S** save request, **Ctrl+L** URL box, **Ctrl+D** duplicate tab, **Ctrl+Tab** / **Ctrl+Shift+Tab**
  switch tabs, **Ctrl+B** beautify, **Ctrl+E** environments, **Ctrl+M** monitors.

**Cleaner windows**
- Settings in tabs (General, Interface, Requests, History, Files).
- Manage Environments grouped into Variables, Request defaults and Authentication.
- Monitor Manager with evenly sized, grouped buttons; a themed WebSocket client.
- A single-row response toolbar with a ⋯ menu (go to line, extract variable, wrap, response position).

**Faster**
- Helper code is compiled once and cached, so later starts are quicker.
- Syntax highlighting is compiled - large responses no longer slow the window down.
- Saved history responses are stored as separate files, so the history loads faster.

## Fixes
- Switching the theme froze the window and only took effect after a restart.
- The first window took long to appear.

## Upgrading
- **From the app:** Help -> About API Tester -> Check for updates -> Download & update, then restart.
- **Manually:** download `API-Tester.ps1` below and replace your copy. Keep the `Configuration`, `History` and `Logs`
  folders next to it - they are no longer part of the download and are created automatically on first start.
- The first start after updating compiles the helper code once; the starts after that are faster.
